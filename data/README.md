# data/

Git-ignored except this file. Created by `make setup`.

- `raw/` untouched source files: `raw/dailymed/`, `raw/openfda/`, `raw/pmc/`
- `processed/` parsed output per source (e.g. label sections), rebuilt from `raw/`
- `cache/` API responses and embeddings, safe to delete
- `outputs/` evaluation outputs, one dated folder per run
